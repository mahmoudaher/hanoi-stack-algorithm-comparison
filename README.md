# Hanoi Stack Algorithm Comparison

C++ implementation and performance comparison of the Towers of Hanoi using recursive and iterative algorithms with stack data structures.

## Demonstrates

- Recursive and iterative Hanoi solutions
- Stack-based data structures
- Move counting
- Execution-time measurements
- Algorithm comparison

## Build

```bash
g++ -std=c++17 -O2 -o hanoi-comparison main.cpp
./hanoi-comparison
```
